# dsh-session-files

为 DeepSeek Harness Web GUI 打造的「当前会话文件」只读浏览插件。与
`dsh-workspace-explorer` 不同：它**不列出所有会话/工作区**，而是只列出
**当前激活会话**工作目录（cwd）下的文件，并以锁靠在主页面右侧的面板展示。

## 入口

- **右击侧边栏的工作区行** → 菜单里有「列出当前会话文件」项（需配合
  `@baihejiangnan/dsh-session-context-menu`，本插件通过其扩展协议注册）。
- **右击会话行** → 同样有「列出当前会话文件」项，面板展示**被右键的那个会话**
  的工作目录（不是当前活动会话的）。
- **右击主窗口（对话区域）** → 菜单里也有「列出当前会话文件」项，此时目标是
  正在展示的活动会话。
- **快捷键 `Alt+W`**：直接打开/关闭面板（无论面板当前状态，等于是开关）。

> 说明：为了让「右击工作区行」也能显示扩展项，本插件依赖对
> `@baihejiangnan/dsh-session-context-menu` 的**小幅增强**——在其工作区行
> 右键菜单里渲染扩展项（原版只给会话行渲染）。

## 面板行为

- 点击后在**主页面右侧**锁靠显示一个只读面板（`position:fixed`，右缘）。
- **默认展示一级目录**下的所有文件夹和文件；点击文件夹可**逐层展开**下一级。
- **默认按文件类型排序**：文件夹在前，随后文件按扩展名类别分组
  （代码 → 配置 → 数据 → 文档 → 图片 → 媒体 → 压缩 → 其他），组内按名称。
- 每行带**按类别着色的 SVG 图标**（文件夹/代码/配置/文档/图片/…）。
- **工作目录**标签与路径分开展示：路径可整段选中，旁边有「复制」按钮。
- **右击任意目录/文件行** → 菜单可**复制路径**、**复制名称**、**在资源管理器中
  打开**（目录打开目录本身，文件打开其所在目录）。
- **点击文件** → 面板底部只显示**文件路径**；文件内容在更大的窗口中展开，窗口
  **铺满侧边栏（会话列表）与右侧目录面板之间的中间区域**、全高，行号竖排显示，
  宽度实时跟随左右两侧列表的调整；行号与文件内容共用一个滚动条、一起滚动。
  **Shift+Esc** 只关闭内容窗口；**Esc** 同时关闭内容窗口和整个面板。
- **面板宽度可调**：拖拽面板左缘的调宽手柄（`ew-resize`）即可改变文件列表宽度，
  内容窗口右缘实时跟随；左侧会话列表宽度变化（展开/收起侧边栏）时内容窗口左缘同样实时跟随。
- **不自动关闭**：点击面板外、背景均不关闭；只有按 **Esc**、点右上角**关闭**
  按钮或 `Alt+W` 才隐藏。

## 安装（link 模式）

本插件作为本地 `link:` 依赖接入 web profile：

```bash
# 1) 把插件目录 link 进 web profile 依赖（已由 profile package.json 声明）
pnpm install --prefer-offline

# 2) 重启 dsh web（Ctrl+C 后重新 dsh web）
# 3) 刷新浏览器，右击工作区/会话行或按 Alt+W 验证
```

## 架构

- **宿主面**（`src/index.js`）：注册自有只读 HTTP API `/session-files-api`
  （`list` / `read`），**不修改任何 DSH 内置包**，也不依赖目录选择器后端组合。
- **客户端面**（`src/client.js`）：通过
  `globalThis[Symbol.for('dsh.session-context-menu.extensions')]` 注册菜单项，
  并在 `ctx.get('sessions').list.getSnapshot()` 读取当前会话 cwd；UI 纯 DOM
  自包含（组件 + SVG 图标 + 样式），不依赖 React/primitives。

## 安全

- **完全本地运行**，不发起任何出站连接、不上传任何文件内容。
- 只读 API 要求**绝对路径**（Windows 要求盘符限定或完整 UNC），拒绝相对/空路径。
- 目录列举单层封顶 1000 条；文件读取默认 256 KiB、硬顶 8 MiB，只读文件头，
  不会把大文件整体载入内存；所有句柄 `try/finally` 关闭。
- 暴露面 = DSH Web GUI 绑定地址（默认回环 127.0.0.1）。**切勿**把带本插件的
  DSH 直接绑定到公网。
